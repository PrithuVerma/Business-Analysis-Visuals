# 📊 American Super Store Sales Analysis – Power BI Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** analyzing sales performance of the American Super Store dataset.

The dashboard provides insights into:

* Sales trends over time
* Profitability analysis
* Regional performance
* Category & sub-category performance
* Customer segmentation
* Discount impact on profit

The objective is to transform raw sales data into actionable business insights.

---

## 🎯 Key Business Questions Answered

* Which regions generate the highest revenue and profit?
* Which product categories are most profitable?
* How do discounts affect profitability?
* What are the monthly and yearly sales trends?
* Which customer segments contribute the most revenue?

---

## 🛠 Tools & Technologies Used

* **Power BI Desktop**
* Data Cleaning & Transformation using **Power Query**
* DAX (Data Analysis Expressions)
* Data Modeling (Relationships, Measures, Calculated Columns)

---

## 📂 Dataset Description

The dataset includes:

* Order ID
* Order Date
* Ship Date
* Customer Name
* Segment
* Region
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit

This dataset simulates real-world retail operations data.

---

## 📊 Dashboard Features

✔ KPI Cards (Total Sales, Total Profit, Total Orders)
✔ Sales by Region (Map / Bar Chart)
✔ Category & Sub-Category Breakdown
✔ Monthly Sales Trend (Line Chart)
✔ Profit vs Discount Analysis
✔ Interactive Filters (Region, Segment, Category, Date)

---

## 📈 Insights Generated

* Certain sub-categories generate high revenue but low profit due to heavy discounting.
* Western region leads in sales performance.
* Consumer segment contributes the highest revenue share.
* Some products consistently operate at a loss.

---
